Discord Maker

Describe your server, preview it and tweak it, and the bot builds it from scratch: channels, roles, verification and onboarding. Then it leaves your server on its own. Free.

1Verify yourself

Enter your Discord user ID (Settings → Advanced → Developer Mode, then right-click your profile → Copy User ID). The bot will send you a code in a direct message. Join my Discord if you have trouble receiving it.

2Describe your server

Builds left: -. Previews are unlimited, only a build uses one.

You need Administrator on it. The bot must have the highest role on that server.

3Preview and edit

Click a channel or category to edit it (names, emoji, visibility, messages). The tabs show roles and onboarding. This is exactly what will be created on the server.

4Build on Discord

Add the bot to your server as an administrator, then confirm. The bot sends you a direct message when it is done and leaves the server by itself.
